# 🎮 YAN TRAPPA Project Master

Простой Telegram бот для управления проектами с мини-играми.

## 🚀 Развертывание на Railway

1. Нажмите кнопку ниже
2. Добавьте переменную окружения:
   - `TELEGRAM_BOT_TOKEN` - токен от @BotFather

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/pTTT5q?referralCode=alpha)

## 📋 Команды бота

- `/start` - Показать список команд
- `/crmp Название` - Создать проект (300,000$ + 2 BTC)
- `/my` - Посмотреть свой проект
- `/balance` - Баланс
- `/bonus` - Получить бонус (55,000-150,000$)
- `/game` - Текущая мини-игра
- `/top` - Топ 10 игроков

## 🎯 Особенности

- Автоматические мини-игры каждые 5 минут
- Простая экономика
- Работает 24/7
- Можно добавить в группу

## 🔧 Технологии

- Python 3.9+
- pyTelegramBotAPI
- SQLite3
